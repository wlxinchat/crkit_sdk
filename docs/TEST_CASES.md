# CRKIT SDK 测试用例设计文档

## 测试范围

### 1. 核心数据结构测试
- Tensor类
- InferenceResult类
- Detection/BBox数据结构
- Status错误处理

### 2. 算法测试
- NMS（非极大值抑制）
- IOU计算
- 置信度过滤
- Top-K选择

### 3. 后处理测试
- 目标检测后处理器
- 多种输出格式解析
- 边界条件处理

### 4. 性能测试
- 内存管理
- 大数据量处理
- 并发安全性
